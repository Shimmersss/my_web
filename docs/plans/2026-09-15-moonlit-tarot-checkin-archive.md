# 月下会客厅牌库、签到塔罗与报告归档

状态：本地完成，未部署。

## 范围与兼容性

- 会客厅入口公开展示现有 22 张大阿尔卡那；沿用现有 WebP 牌面与 `TarotHoloCard`，不生成 Blender 工程。
- 新关系探索顺序为“关系情境、抽三张牌、人格问卷、关系偏好、生活底稿、核对提交”；24 小时内未消费牌阵继续复用。
- 账号每日签到在同一事务中持久化牌库版本、牌 ID、牌面快照、积分与流水；同一上海自然日固定同牌，旧签到只补牌不补积分。婚恋内测身份继续不参与签到。
- 报告归档折叠时显示最近 3 份，展开后按月分组、每页 10 份；root 可按用户名筛选。旧列表接口、报告正文、权限和历史数据保持兼容。

## 数据与回滚

- `daily_checkins` 仅增加三个可空列：`deck_version`、`card_id`、`tarot_payload`。启动迁移可重复执行，不删除或重算历史记录。
- 并发签到先锁定用户行，再读取和创建当日签到，避免 MySQL 可重复读下的重复键死锁；任一步失败均回滚牌面、积分和流水。
- 回滚代码不会丢失新增列或快照；旧版本可忽略可空字段。新生成报告及既有三张牌记录无需转换。

## 验证

- Java 定向测试覆盖 22 张公开牌库、每日指引、签到关闭/重复/并发/旧记录补牌/回滚/上海自然日和归档权限分页。
- Java 全量测试 160 项通过；前端完整构建及既有 PWA、导航、Android WebView、PDF 预览门禁通过。
- 独立临时 MySQL 实例通过增量迁移、四路并发签到、旧签到补牌、退款并发与任务恢复，随机测试库由测试清理。
- 本地浏览器确认桌面 5 列、390px 3 列、320px 2 列，无横向溢出；牌义弹层支持 Esc 和焦点返回；抽牌位于人格问卷前，未抽牌无法继续；全息牌左右倾斜时流光变化且文字可读。
- Android App 加载生产站点，本轮没有原生容器改动，未升 APK；待生产发布后用模拟器或真机对线上站点复验。

## 发布边界

本轮没有生产发布授权，也没有修改生产数据库、开关、站点文件或 Android 更新清单。可与 BabelDOC 单页保底代码合并为同一个候选发布，但必须按 `DEPLOYMENT.md` 重新执行发布门禁、备份、迁移和线上验收。
