# 月下收藏库与抽卡页：界面原型

当前首版与剩余任务见 [后续交接](2026-09-18-moonlit-collection-handoff.md)，本计划不代表已全部实现或验收。

## 范围与边界

用户确认月夜展馆视觉：22个固定卡位，未获得显示黑牌背、编号与牌名，首次获得点亮；重复获得累计进度，逐步开放四个独立升级主题。签到和专属抽卡计入收藏，关系探索牌阵不计入；每日免费和签到共用机会，另有积分单抽，无十连。

本次实现隔离的前端演示，不接真实签到、积分扣费、收藏数据库或业务抽牌API。演示金额、阈值和随机结果均非正式规则。历史签到追溯、正式等级与经济配置留待后续业务设计。用户只授权本地实现与验收，未部署。

## 界面与实现约束

- 独立收藏库和抽卡路由，避开现有报告ID动态路由；关系探索保留入口和原有三张牌流程。
- 默认0/22全黑，提供明确的演示样例控制；静态卡墙桌面6列、平板4列、手机2列。
- 已获得大卡、五主题槽位、解锁进度、设为展示；未获得可读牌义但隐藏原画。未制作主题不能用基础原图冒充。
- 抽卡经历等待、揭牌、结果，支持首次、重复、升级、失败、余额不足。获得结果即入演示收藏，动画与查看收藏不产生二次扣除。刷新恢复既有结果。
- sessionStorage独立命名空间持久化，演示重置只清除自身数据；不存会话令牌，不读写真实余额。
- 减少动态效果偏好、键盘、对话框焦点、单一main/h1、手机触控和无横向溢出。
- 主代理验收，Sol子代理实现；不改既有塔罗美术工程和其他任务文件。

## 验收清单

1. 完整前端构建与既有导航/内测/Android/PWA/PDF门禁。
2. 1440px、390px、320px卡墙/抽卡页/详情；默认22张黑牌、标题与按钮可读，列数正确。
3. 真实浏览器完成免费抽取、揭牌、收藏点亮、重复、升级、主题切换与刷新；余额不足/失败不扣演示余额、不消耗免费机会。
4. 演示页不发送签到、积分或抽牌写请求；原关系探索入口及路由仍可用。
5. 对话框关闭恢复焦点、键盘可操作，减少动态效果时结果仍可读。
6. 核对素材请求、控制台、浏览器截图和最终diff，发现问题返修后复验。

## 回退

移除新路由/入口和独立组件、演示状态即可；无数据库迁移或生产资产替换。不删除现有美术样本、历史报告或实际账户数据。
