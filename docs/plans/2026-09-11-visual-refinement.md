# 全站视觉精修

目标：沿用中文个人研究工具站的暖白、朱红与衬线标题，降低底色饱和度和边框噪声，统一留白、圆角、阴影及交互反馈。关系探索保持独立月夜视觉。

范围：共享主题、导航/页脚、首页、文献、翻译、PPT、生图、GitHub、留言、下载与后台的显示层。动效采用 CSS 短时入场、悬停反馈及首页轻视差；适配减少动态效果偏好。现有未提交关系探索改动保留，不修改业务接口、权限、计费、任务状态或部署配置。

风险与验证：样式层叠、窄屏溢出、深色模式文字对比、弹窗与固定定位。执行前端完整 build，浏览器检查桌面、390px、320px，验证导航/主题/表单/空态及控制台；不提交收费任务，不改变已有数据。减少动态效果时内容保持可见，不用全局裁切掩盖布局问题。

回滚：仅撤回本轮样式与显示层修改，保留工作区既有业务变更；无数据库迁移。当前范围为本地实现与验证，生产部署需另行授权。
