## 本次锁定与未锁定

- **锁定**：每牌独立制作；各升级主题静止时就明显不同；环境、主体设计、前景、边框与材质共同设计；以多张真实透明图片构成景深。
- **范本**：[月亮五样本指南](moon-sample-guide.md)。五套均可参考，迁移主题差异、完整支撑、透明边缘和材质方法，不复制月亮象征。
- **五个外观槽位**：基础原画 + 四个新主题。2–5 是建议展示顺序，可调整；每个主题都可以使用完整分层闪卡能力，不再规定只有高等级才能有景深。
- **内容变化**：允许画内人物服饰、物件材质、场景与构图创新，保留各牌核心象征与人物关系；牌义与现有报告文案不改。主题名可用于展示，故事文案不自动生成或写入业务。
- **未锁定**：积分价格、成长阈值、成长事件来源、满级重复奖励、等级绑定。制作素材不等于实现升级系统。
- 月亮五套已有本地分层工程，四套刚完成返修复验，最终审美状态见各manifest。其余21牌中，太阳、审判及命运之轮「潮汐轮盘」已有不同阶段的本地结果；其他槽位以各 manifest 为准，基础原图保留，不重画。

88 是母版目标数，不是总调用次数。拆层、返工和候选另计。优先复用月亮现有成果，不重复花费生成。完整系列最终为 110 个外观槽位，本次将其他21张基础图的分层闪卡纳入制作计划；保留基础图本身不变。

## 范本的改进须知

深海幻月已通过两组 33 项网页检查（390px/320px），并人工检查左右倾斜。此结果只适用于该原型，不给其他牌自动放行。

原型遇到烘焙棋盘底，最终通过重新生图为纯绿主体底、纯黑发光前景底并提取 alpha 修复。绿色提取阈值、银框几何遮罩和稀疏线稿阈值是该图专用，其他牌不能照抄数值当作通过。软透明天使、流水、浅色毛发尤其需要人工核对。

生产状态、模型调用输入与图片来源必须写到各主题 manifest。本文授权边界为制作规范；Terra 的执行与批量生图由用户后续任务触发，本轮没有启动 Terra、生成新图或部署。

## 规格优先级

业务边界与统一质量门按 production-rules；具体构图、连接组和参数按逐牌制作单及JSON的 productionDetail。JSON与逐牌单须同步修改。参数都是待实测起点，主题状态不得由文档完成自动改成已生成。
