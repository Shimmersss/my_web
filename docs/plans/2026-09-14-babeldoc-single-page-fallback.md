# BabelDOC 单页保底分片

状态：本地实施中，未部署。

## 问题

生产任务 `es1c02376.pdf`（11 页、含多张图片）在三页分片下，即使已降至稳定 QPS，仍因可用内存低于安全线而被资源保护中止。现有恢复只会降低 QPS；它不能在稳定 QPS 仍发生压力时进一步缩小分片。

## 范围

- PDF 翻译在稳定 QPS 的资源压力重试仍失败时，自动将尚未完成的范围改为一页一批。
- 复用兼容的已完成分片，不重新翻译已经成功的页。
- 将保底状态写入任务元数据，并经 SSE 显示可理解的进度说明；单页模式再触发资源保护时仍保持失败、退款和现有硬限制。
- 添加服务级回归测试，验证 QPS 降级后的一页分片调用、完成结果与无重复扣费。

## 不包含

- 不降低内存、cgroup、Swap 的安全阈值；不绕过资源保护。
- 不部署、不重跑生产任务、不改变积分定价。

## 验证与回滚

- 定向翻译服务测试、完整 Maven 测试和 `git diff --check`。
- 该改动只影响运行时重试策略；回滚代码会恢复此前的“稳定 QPS 下失败即退款”行为，已完成磁盘分片仍可由现有缓存兼容逻辑读取。

## 结果

已实现：任务元数据持久化单页保底状态；资源压力先降至稳定 QPS，稳定 QPS 再失败时才改用一页一批和稳定 QPS。该模式仍有一次资源恢复等待，单页模式再遇资源压力会走原有失败与退款路径。回归测试确认了完整的两次压力触发、逐页参数和成功完成路径。
