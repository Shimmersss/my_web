## 资源目录约定

```text
output/tarot-progression/v2/major-XX/theme-YY/
├── source/master-v01.png       # 选定的完整不透明母版
├── production-notes.md         # 实际调用、路径、哈希与异常
├── manifest.json               # 可机读状态和后续制作入口
└── README.md                   # 主题目录说明
```

系列汇总以 [`series-manifest.json`](../../output/tarot-progression/v2/series-manifest.json) 为入口；它的状态应在每次主题目录变更后同步。
