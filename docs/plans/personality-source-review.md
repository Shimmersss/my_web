候选28题不再作为新任务的正式题库。因原题文权利来源未确认，按交接19.3退回本站新编16题，版本为 `personality-original-16-v1`；四轴各4道二元题，仅用于关系自我观察，没有量表信效度背书。平票显示均衡，类型码以 X 表示未知轴，不强行判成某一侧。题面在本次返修中新编，未复用候选题文字；历史下载资料不变，旧报告按保存结果展示，不重算。

新任务向模型提供带题意的实际回答，并按本次回答集合校验证据；自报与跳过不能引用人格问卷题号。牌义逐牌历史核对仍未完成，保留为发布前待办，不宣称已验收或已授权上线。

## 历史选型记录（已被上文替代，非当前规范）

本次关系探索报告采用固定的 `personality-28-v1`，题面以本地审查资料中的 28 题为基础并改写为关系自我观察语境。产品文案统一称“关系人格倾向”，不称官方 MBTI 测评，不宣称准确率、诊断能力或临床/科学结论。

服务端只接受上游计算器使用的二元选项值 `1/2`，按 EI、SN、TF、JP 四轴分别计数；未引入旧版婚恋条件报告的 `[-2,2]` 算法，也没有把 IPIP 大五条目映射成四字母类型。

## 实现核对

- `RelationshipQuestionnaire` 发布 `relationship-questions-v1`、`personality-28-v1` 和 28 个固定 `p01`–`p28` 题目。
- `RelationshipPersonality` 仅在问卷路径执行确定性四轴计数；自报和跳过路径不会伪造测量结果。
- `RelationshipReportAgent` 的提示词和结构校验都禁止诊断、预测、胜率和人格优劣；`evidenceIds` 只能引用 `p01`–`p28`、`r01`–`r05`。
- 题库来源、内容版本和报告版本写入服务端/报告载荷；旧 `market-positioning-v3` 路径继续使用旧题库和算法。
